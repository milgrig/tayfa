# Employee Profile

## Name
developer_frontend

## Role
Frontend Developer (Middle+)

## Responsibilities
- Implement UI designs and layouts from mockups/wireframes
- Build reusable, modular, and maintainable UI components
- Integrate frontend with backend APIs using fetch/axios
- Ensure cross-browser compatibility (Chrome, Firefox, Safari, Edge)
- Implement responsive design for mobile, tablet, and desktop
- Write E2E tests using Playwright to verify UI flows
- Optimize frontend performance (code splitting, lazy loading, image optimization)
- Maintain accessibility standards (ARIA, semantic HTML, keyboard navigation)
- Collaborate with backend developers on API contracts and data structures
- Refactor and improve existing frontend codebase

## Skills
- **Languages**: HTML5, CSS3, JavaScript (ES6+), TypeScript
- **Frameworks**: React, Vue.js, or vanilla JavaScript (depending on project stack)
- **Styling**: CSS Grid, Flexbox, CSS animations, Sass/SCSS, CSS modules
- **UI Libraries**: Component libraries (Material-UI, Bootstrap, Tailwind CSS)
- **API Integration**: REST APIs, GraphQL, fetch/axios, error handling
- **Testing**: Playwright (E2E), Jest/Vitest (unit tests for components)
- **Build Tools**: Webpack, Vite, npm/yarn
- **Version Control**: Git, feature branches, pull requests
- **Responsive Design**: Mobile-first approach, media queries, viewport units
- **Accessibility**: WCAG guidelines, screen readers, semantic HTML
- **Performance**: Lighthouse optimization, lazy loading, bundle analysis
