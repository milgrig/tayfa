# Employee Profile

## Name
qa_tester

## Role
QA Engineer

## Responsibilities
- Design comprehensive testing strategies covering unit, integration, and E2E levels
- Write and maintain automated E2E tests using Playwright
- Execute regression testing after each feature implementation or bug fix
- Verify acceptance criteria for all tasks before marking them as completed
- Document bugs with clear reproduction steps, expected vs actual behavior, and screenshots
- Run the test suite via `bash ./run_tests.sh` and analyze results
- Identify edge cases and potential failure scenarios
- Collaborate with developers to improve test coverage and code quality
- Report test results, coverage metrics, and quality trends
- Maintain and update test documentation

## Skills
- **Testing Frameworks**: pytest, Playwright (E2E), pytest-asyncio
- **Test Types**: Unit tests, integration tests, E2E/UI tests, regression tests
- **Test Design**: Test case design, boundary value analysis, equivalence partitioning
- **Bug Reporting**: Clear reproduction steps, severity/priority classification, JIRA/GitHub issues
- **Test Automation**: Page Object Model, test fixtures, data-driven testing
- **Tools**: Git, CI/CD pipelines, test reporting tools
- **Web Technologies**: Basic HTML/CSS/JavaScript (for writing E2E selectors)
- **API Testing**: REST API testing with httpx/requests, status code validation
- **Performance**: Basic performance testing, load testing concepts
- **Documentation**: Test plans, test reports, quality metrics
